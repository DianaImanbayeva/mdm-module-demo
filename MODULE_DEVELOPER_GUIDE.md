# Руководство по разработке модулей для ERP Core

Добро пожаловать! Вы приглашены для разработки независимого модуля для центральной ERP-системы. 
Наша ERP использует микросервисную архитектуру. Вы разрабатываете свой модуль как полностью самостоятельное веб-приложение.

---

## 🔐 1. Что вам передаст Заказчик
Для работы вам не нужен исходный код ERP или доступ к центральной базе данных. Заказчик передаст вам только **одну секретную строку**:
- **`JWT_SECRET`** (Например: `super-secret-key-12345...`) — это ключ для расшифровки пропусков пользователей.

## 🛠️ 2. Контракты и конфигурация модуля (Module SDK)
Чтобы наша система приняла ваш модуль, он должен соответствовать единому стандарту контрактов.

### Файл `module.json` (Обязательно)
В корне вашего сервера обязательно должен находиться файл `module.json`. Наша система (API Gateway) будет считывать его при подключении.
Пример формата:
```json
{
  "name": "Название модуля (например: Склад)",
  "version": "1.0.0",
  "icon": "📦", 
  "endpoints": {
    "health": "/health",
    "api": "/api/v1"
  },
  "scopes": ["read", "write"]
}
```

### Проверка доступности (Contract Testing)
Ваш сервер **обязан** иметь рабочий эндпоинт `/health`, который возвращает HTTP статус `200 OK`. При попытке администратора добавить ваш модуль, ERP-система сделает тестовый запрос на этот адрес. Если ответа не будет — модуль не подключится.

## 🖼️ 3. Интеграция интерфейса (Micro-frontends)
Наша ERP использует архитектуру Micro-frontends. Подключение интерфейса возможно двумя способами:
1. **Через Iframe (Простой способ):** Ваш веб-интерфейс загружается внутри окна ERP. Для этого вы обязаны настроить HTTP-заголовки `X-Frame-Options: ALLOWALL` и `Access-Control-Allow-Origin: *`.
2. **Через Module Federation (Продвинутый способ):** Если вы пишете на React/Webpack, вы можете собрать интерфейс в виде `remoteEntry.js`. Заказчик укажет ссылку на ваш бандл, и он будет бесшовно встроен в DOM дерева ERP (без iframe).

## 🔐 4. Как работает интеграция (SSO)
Ваш модуль будет открываться внутри интерфейса ERP через `iframe`.

Когда пользователь в ERP кликает на ваш модуль, наша система загрузит ваш URL и прикрепит к нему токен авторизации:
`GET https://ваши-финансы.com/?token=eyJhbGciOiJIUzI1...`

**Ваша задача:**
1. Поймать этот `token` из URL.
2. Проверить его подлинность с помощью ключа `JWT_SECRET`, который дал заказчик.
3. Если токен подлинный — значит, пользователь авторизован. 

Внутри расшифрованного токена (Payload) вы увидите следующие данные:
```json
{
  "sub": "user-uuid-123", // ID пользователя
  "email": "ivan@example.com", 
  "role": "manager",
  "app_metadata": {
    "organization_id": "org-uuid-456" // ID компании (Очень важно!)
  }
}
```
*Важно: Вы должны сохранять все данные в вашей базе с привязкой к `organization_id`, чтобы изолировать данные разных компаний.*

## 💻 3. Примеры кода для вас (Как проверить токен)

Токен подписан алгоритмом **HS256**. Используйте стандартные библиотеки.

**Если вы пишете на Node.js / Express:**
```javascript
const jwt = require('jsonwebtoken');

app.get('/', (req, res) => {
    const token = req.query.token;
    
    try {
        // Проверяем подпись (никто не сможет подделать токен без SECRET)
        const decoded = jwt.verify(token, process.env.JWT_SECRET);
        
        const userId = decoded.sub;
        const orgId = decoded.app_metadata.organization_id;
        
        res.send(`Добро пожаловать! Вы из компании ${orgId}`);
    } catch (err) {
        res.status(401).send('Ошибка доступа: Токен недействителен');
    }
});
```

**Если вы пишете на PHP:**
```php
require 'vendor/autoload.php';
use \Firebase\JWT\JWT;
use \Firebase\JWT\Key;

$token = $_GET['token'] ?? null;
$secret = 'ВАШ_JWT_SECRET';

try {
    $decoded = JWT::decode($token, new Key($secret, 'HS256'));
    $orgId = $decoded->app_metadata->organization_id;
    echo "Вы успешно вошли. Ваша компания: " . $orgId;
} catch (Exception $e) {
    http_response_code(401);
    echo "Доступ запрещен";
}
```

## 🗄️ 4. База данных
Вы создаете и администрируете **свою собственную базу данных** (MySQL, Postgres и т.д.) для хранения логики вашего модуля (например, таблица товаров или продаж). Вы не имеете прямого SQL-доступа к центральному Ядру ERP.

## 🚀 5. Сдача работы
Чтобы модуль заработал в интерфейсе, настройте свои HTTP-заголовки, чтобы разрешить загрузку в Iframe:
- `X-Frame-Options: ALLOWALL` 
- `Access-Control-Allow-Origin: *`

Когда всё готово, просто отдайте Заказчику ваш URL (например, `https://sales-module.kz`). Заказчик вставит его в админку ERP, и модуль запустится!
